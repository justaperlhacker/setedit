# Building SETEdit

This repository is the canonical SETEdit suite (`setedit/code` from
SourceForge): the editor and `infview` live under `setedit/`; `AlCon/` and
`cal/` are extra tools that are **not** part of this build.

SETEdit does **not** use autotools. `setedit/configure` is a thin wrapper that
runs `setedit/config.pl`, a Perl script which probes the toolchain and writes
makefiles plus `setedit/makes/rhide.env`. Turbo Vision must be built first.

See `REVIVAL-PLAN.md` for the two `config.pl` fixes this revival uses.

## 1. Prerequisites

- `gcc`, `g++`, `make`, `perl`, `git`, binutils
- Development files for: **ncurses**, **gpm**, **X11**, **Xmu**, **zlib**,
  **bzip2**, **pcre**

Arch / CachyOS:
```sh
sudo pacman -S --needed base-devel ncurses gpm libx11 libxmu zlib bzip2 pcre perl git
```
Debian / Ubuntu:
```sh
sudo apt install build-essential perl git libncurses-dev libgpm-dev \
  libx11-dev libxmu-dev zlib1g-dev libbz2-dev libpcre3-dev
```

## 2. Turbo Vision (static)

The editor links a static Turbo Vision built from the modern-gcc fork:

```sh
mkdir -p ~/Projects && cd ~/Projects
git clone https://github.com/justaperlhacker/tvision.git
cd tvision
git checkout modern-gcc
cd tvision
./configure --without-dynamic
make -j"$(nproc)"
ln -sf "$PWD/rhtv-config" ~/.local/bin/rhtv-config   # config.pl calls this
```

`~/.local/bin` must be on `PATH`. (Alternatively pass the paths explicitly in
step 3.)

## 3. Configure and build the editor

```sh
cd ~/Projects/setedit/setedit            # or wherever this repo's setedit/ is
./configure \
  --tv-include="$HOME/Projects/tvision/tvision/include" \
  --tv-lib="$HOME/Projects/tvision/tvision/makes"
make -j"$(nproc)"
```

Outputs:

| file | what |
|------|------|
| `makes/editor.exe` | the editor (`setedit`) |
| `makes/infview.exe` | the InfoView file viewer |

Configuration summary is printed; the last line should read
`Successful configuration!`.

### Build variants

```sh
# editor only (skip infview)
./configure --no-infview --tv-include=... --tv-lib=...
make -j"$(nproc)"

# the shared library RHIDE links against (libset.a), no editor/infview
./configure --libset --no-infview --tv-include=... --tv-lib=...
make needed
make libset
```

Useful configure switches: `--prefix=DIR`, `--static` (full static link;
usually fails against dynamic system libs), `--infview` / `--no-infview`,
`--libset` / `--no-libset`, `--help`.

## 4. Run

The editor must be told its install prefix via `SET_FILES`:

```sh
# native X11 window
env DISPLAY=:0 SET_FILES=/usr ./makes/editor.exe

# terminal driver instead
env -u DISPLAY SET_FILES=/usr ./makes/editor.exe

# open a file
env DISPLAY=:0 SET_FILES=/usr ./makes/editor.exe path/to/file
```

The X11 window sets `WM_CLASS = "tvapp", "SETEdit"`.

## 5. Install

```sh
./configure --prefix=/usr --tv-include=... --tv-lib=...
make -j"$(nproc)"
sudo make install          # installs editor as "setedit", plus infview, docs
```

The Linux install path is `makes/linux/compress.pl` (invoked by
`make -C makes install`). Package targets (`debian/`, `redhat/`) exist but are
untested in this revival.

## 6. Reconfigure and clean

```sh
./configure ...    # re-run after editing config.pl
make clean         # objects, libs, binaries, generated Makefile, cache
```

The generated `setedit/Makefile` refuses to build if `config.pl` is newer than
it (`Please reconfigure the package!`).

## 7. Troubleshooting

- **`undefined reference to 'stdscr' / 'wgetch' / 'XLookupKeysym'`** — the TV
  link libraries are wrong. This tree takes them from `rhtv-config --slibs`;
  make sure *our* `rhtv-config` (from the static fork) is the one on `PATH`.
- **`Wrong installation! You must define the SET_FILES environment variable`** —
  export `SET_FILES=/usr` (or your prefix) before running the editor.
- **`make` reports `Please reconfigure the package!`** — re-run `./configure`.
- **`makeinfo ... Broken!` / `AA lib is not installed`** — optional docs and
  the console screen-saver; harmless.
- **No debug features** — the built-in debugger needs `libmigdb`, a separate
  SourceForge project that is not shipped here.
- **`-Wold-style-definition` / `-Wregister` warnings** — cosmetic; the tree
  does not use `-Werror`.
